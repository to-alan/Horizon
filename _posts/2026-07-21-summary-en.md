## [Fastjson 1.x Critical RCE Vulnerability Without Gadgets](https://x.com/k_firsov/status/2078872293745570032) ⭐️ 9.0/10

A remote code execution vulnerability has been disclosed in Fastjson 1.x versions 1.2.68 to 1.2.83, requiring no autoTypeSupport or classpath gadgets, and affecting JDK 8, 17, and 21. No official patch will be released as Fastjson 1.x is end-of-life since October 2024. This vulnerability is critical because Fastjson is a widely used JSON parsing library in Java projects, and the exploit does not require complex conditions, putting many applications at immediate risk. Users must upgrade to Fastjson2 or enable SafeMode to mitigate the threat. The vulnerability bypasses the need for autoTypeSupport and classpath gadgets, which were previously required for exploitation. The only mitigations are upgrading to Fastjson2 or enabling SafeMode via JVM startup parameters or configuration files.

telegram · zaihuapd · Jul 20, 14:32

**Background**: Fastjson is a high-performance JSON library for Java, commonly used in enterprise applications. Since version 1.2.68, SafeMode was introduced to completely disable autoType and prevent deserialization attacks. This vulnerability is particularly dangerous because it does not rely on autoType or known gadget chains, making it harder to block with traditional blacklists.
