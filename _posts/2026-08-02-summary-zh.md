## [OpenAI Astra 在十项长期数学难题上取得突破](https://openai.com/index/ten-advances-in-mathematics/) ⭐️ 10.0/10

OpenAI 宣布，其下一代模型 Astra 的内部版本在十个长期未解决的数学与理论计算机科学问题上取得了新成果，这些问题至少十年没有重大进展。人类研究员将这些论证整理成论文，并在 Lean 证明助手中进行了形式化验证，据报告 token 成本约为 2000 美元。 这一里程碑表明，大语言模型能够以极低的计算成本，在人类数学家数十年未解的问题上做出原创性进展。这也引发了关于 AI 在研究中的署名、验证方式以及如何正确归功于 AI 的重要讨论。 这十项成果包括高维球体堆积界限的改进、非索菲克群的存在性、Connes 刚性猜想的反例、算术电路下界、量子平行重复、最近向量问题的近似困难性以及多色 Ramsey 数等。OpenAI 在 GitHub 上公开了 'openai/ten-proofs' 仓库，包含 Lean 4 形式化验证、一篇研究论文和一份由模型生成的推理过程还原文档。

## [微软发布 TRELLIS.2，实现高效 3D 生成](https://github.com/microsoft/TRELLIS.2) ⭐️ 9.0/10

微软开源了 TRELLIS.2，这是一个 40 亿参数的图像转 3D 模型，采用新颖的“O-Voxel”稀疏体素表示，可生成高达 1536³分辨率的高质量 PBR 纹理 3D 资产。此次发布包括研究论文、Hugging Face 上的模型权重和交互式演示。 TRELLIS.2 大幅降低了 3D 资产创建的成本和时间，使游戏、VR/AR 和电影制作中的实时生成成为可能。其原生态结构化潜变量方法还能处理开放表面、非流形几何等以往方法难以处理的复杂拓扑。 该模型采用 16 倍空间下采样的稀疏 3D VAE，在 H100 GPU 上约 3 秒即可生成 512³分辨率的资产。它支持任意表面属性，如基色、粗糙度、金属度和不透明度，并且其数据处理完全无需渲染和优化。

rss · GitHub Trending - Python Daily · 8月1日 01:48

**背景**: TRELLIS.2 是微软大型 3D 生成模型 TRELLIS 的继任者，后者引入了结构化潜变量（SLAT）。SLAT 使用从渲染图像视图推导出的稀疏体素结构，而 O-Voxel 是一种“无场”的全向体素表示，直接从原生 3D 数据编码几何和外观。这种方法减少了预处理开销，并提升了对复杂结构的保真度。

## [OpenAI 发布 Whisper，一款鲁棒的多语言语音识别模型](https://github.com/openai/whisper) ⭐️ 9.0/10

OpenAI 已开源 Whisper，这是一个通过大规模弱监督训练的通用水语音识别模型。它能在单个 Transformer 序列到序列模型中完成多语言语音识别、语音翻译、语言识别和语音活动检测。 Whisper 的重要意义在于，单一多任务模型可以取代传统语音处理流程中的多个环节，从而降低构建强大语音 AI 的门槛。其开源发布让开发者和研究人员都能广泛使用这一前沿的多语言模型。 该模型将任务表示为由解码器预测的 token 序列，并使用特殊 token 作为任务说明符或分类目标。Whisper 提供六种模型尺寸，其中四种为仅英文版本，在速度和准确性上有所权衡；安装时还需要 ffmpeg，在某些平台上可能还需要 Rust 来编译 tiktoken。

rss · GitHub Trending - Python Daily · 8月1日 01:48

**背景**: Whisper 基于 Transformer 的序列到序列架构，编码器处理音频输入，解码器生成输出 token。它采用弱监督训练方法，这是一种利用大规模、可能不完美的自动标注数据而非人工核实标签的机器学习范式。该模型还集成了语音活动检测技术，用于判断音频流中是否存在人类语音，从而帮助模型处理多样化的音频输入。

## [MCP Apps 为 AI 聊天机器人带来标准化交互界面](https://github.com/modelcontextprotocol/ext-apps) ⭐️ 9.0/10

Model Context Protocol 组织发布了 MCP Apps 协议规范与 SDK 的官方仓库，定义了在 AI 聊天机器人中嵌入交互式 UI 组件（如图表、表单、仪表盘）的标准。此次发布包含 npm 上的 TypeScript SDK、四个 Agent Skills 以及一份日期为 2026-01-26 的规范，并支持在 Claude 和 ChatGPT 等客户端中内联渲染。 这很重要，因为它将 MCP 从仅返回文本的工具结果扩展到丰富的交互式界面，有望成为 AI 助手展示数据和收集用户输入的标准方式。构建 MCP 服务器和工具的开发者现在可以创建图表、表单和仪表盘，并在 Claude、ChatGPT 及其他兼容客户端中无缝渲染。 MCP Apps 运行在由宿主客户端控制的沙箱 iframe 中，为执行第三方 UI 代码提供了安全保证。该仓库在 npm（@modelcontextprotocol/ext-apps）上发布了 TypeScript SDK，并附带四个 Agent Skills，使 AI 编程代理能够自动生成 MCP Apps。

rss · GitHub Trending - TypeScript Daily · 8月1日 01:52

## [全球首个全光子时间晶体问世，为超高速计算铺路](https://www.ithome.com/0/984/640.htm) ⭐️ 9.0/10

研究人员首次实验制备出全球首个全光子时间晶体，这种超材料的光学特性可在皮秒时间尺度上快速、反复地变化。该成果于 2026 年 7 月 29 日发表在《自然》期刊上，由巴黎综合理工学院、法兰西公学院和亥姆霍兹德累斯顿-罗森多夫研究中心（HZDR）的科学家共同完成。 这一突破证明光可以在以往不可能的方式下被动态控制，为超高速计算机、自适应通信系统和新一代太赫兹激光器开辟了道路。由于时间晶体打破了时间平移对称性，它有望催生工作在光学频率下的全新光子器件。 这种等离子体超材料由微米级金凹槽结构、绝缘层和铟锑半导体材料构成。团队利用 HZDR 的 ELBE 加速器上的 TELBE 太赫兹源，以太赫兹频率驱动材料，观察到其进入光子时间晶体状态，且等离子体损耗降低。未来研究将致力于进一步减少损耗、增加光子数量，以实现太赫兹光放大。

rss · IT之家 · 8月1日 22:57

**背景**: 光子晶体是一种具有周期性折射率变化的纳米结构材料，能像半导体控制电子一样控制光子的传播。而时间晶体的特性则会随时间周期性变化。在这项实验中，研究人员实现了皮秒级的光学特性调制，与光自身的振荡周期相当。该器件利用表面等离激元——金属-介质界面上的相干电子振荡——来捕获光，并由 TELBE 太赫兹源提供高强度、可调谐的脉冲来驱动系统。
