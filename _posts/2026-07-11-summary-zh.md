斯坦福 NLP 发布了 DSPy，这是一个 Python 框架，用算法优化提示和模型权重取代了手动提示。它允许开发者通过组合式 Python 代码构建模块化 AI 系统，如分类器、RAG 流水线和智能体循环。 DSPy 代表了一种从脆弱的手工提示到程序化、自我改进流水线的范式转变，显著提高了 LLM 应用的可靠性和性能。这种方法可能标准化开发者构建和优化 AI 系统的方式，减少试错工作量。 DSPy 代表声明式自我改进 Python，包含自动教 LM 产生高质量输出的优化算法。它支持从简单分类器到复杂多阶段流水线的广泛任务，其基础研究已发表在多篇学术论文中。

## [Bun：全能高速 JavaScript 运行时与工具链](https://github.com/oven-sh/bun) ⭐️ 9.0/10

Bun 是一个全新的全能 JavaScript 运行时，集成了打包器、测试运行器和包管理器，使用 Rust 从头构建，基于 JavaScriptCore 引擎，启动和执行速度比 Node.js 及现有工具快得多。 Bun 用一个单一二进制文件替代了多个独立工具（Node.js、webpack、npm、Jest），简化了 JavaScript 开发工具链，显著提高开发者效率并减少配置负担。其性能优势可能使其成为许多项目中 Node.js 的有力替代品。 Bun 原生支持 TypeScript 和 JSX，可作为 Node.js 的即插即用替代品，并支持 Linux、macOS 和 Windows。它内置了兼容 npm 包的包管理器，并能运行 package.json 中定义的脚本。

rss · GitHub Trending - Rust Daily · 7月10日 01:41

**背景**: JavaScript 应用程序通常需要多个独立工具：一个运行时（如 Node.js）来执行代码，一个打包器（如 webpack）来合并模块，一个测试运行器（如 Jest），以及一个包管理器（如 npm）。Bun 将这些功能整合到一个可执行文件中，用 Rust 编写以获得高性能，并使用 JavaScriptCore（Safari 使用的引擎）替代 V8（Node.js 使用的引擎），以减少启动时间和内存占用。
