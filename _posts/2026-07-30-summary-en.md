## [Open-source engine runs 26B model on Mac with 2GB RAM](https://github.com/drumih/turbo-fieldfare) ⭐️ 8.0/10

TurboFieldfare, an open-source inference engine written in Swift and Metal, runs a 4-bit quantized Gemma 4 26B model on any M-series Mac using only about 2 GB of RAM by streaming routed experts from SSD, achieving 5–6 tok/s on an M2 MacBook Air and 31–35 tok/s on an M5 MacBook Pro. This significantly lowers the barrier for running large Mixture-of-Experts models on consumer hardware, enabling powerful on-device AI without expensive GPUs. It demonstrates a practical approach to overcome memory constraints by leveraging SSD streaming, which could influence future inference engine designs. The 4-bit quantized weights occupy about 14 GB, but only shared layers and KV cache (≈2 GB) are kept in RAM; routed experts are streamed from SSD using a 16-slot cache with 67% hit rate. The engine requires macOS 26 for full prefill speedup but works on earlier versions with minor code adjustments.

hackernews · gitpusher42 · Jul 29, 15:05 · [Discussion](https://news.ycombinator.com/item?id=49098510)

**Background**: Mixture of Experts (MoE) models like Gemma 4 26B have many parameters but only activate a subset per token, making them efficient for inference. However, conventional inference loads all weights into RAM, which is prohibitive for large models on low-memory devices. 4-bit quantization further reduces memory footprint. Streaming experts from SSD is an innovative technique that trades latency for memory, as SSD is slower but much larger than RAM.

## [TokenSpeed: New LLM Inference Engine Optimized for Agentic Workloads](https://github.com/lightseekorg/tokenspeed) ⭐️ 8.0/10

TokenSpeed, a new open-source LLM inference engine developed by LightSeek Foundation, was announced in May 2026 and has achieved 580 tokens per second on Qwen3.5-397B-A17B for agentic workloads. It combines the performance of TensorRT-LLM with the usability of vLLM through a novel local-SPMD design and static compiler. Agentic workloads, where AI agents autonomously perform tasks, place unique demands on inference engines, such as long-lived KV cache and decode-dominated execution. TokenSpeed is specifically designed for these workloads, offering a significant performance improvement that could accelerate the deployment of AI agents in production. Its open-source nature also fosters community adoption and innovation. TokenSpeed features a local-SPMD (Single Program Multiple Data) modeling layer where a static compiler automatically generates collective communication from module-boundary placement annotations, eliminating the need for manual parallelism logic. Its pluggable kernel system includes one of the fastest implementations of Multi-head Latent Attention (MLA) on Blackwell GPUs. The scheduler uses a finite-state machine encoded in C++, with safe KV cache reuse enforced at compile time. It has demonstrated 580 tokens per second on the Qwen3.5-397B-A17B model.
